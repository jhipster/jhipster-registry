Using SSH with Docker

Here are detailed instructions for the JHipster Registry Docker image, available at jhipster/jhipster-registry. The image has no SSH tools, so you prepare the SSH settings on your machine and mount them.

  • Create a directory for the SSH settings of the registry and generate a key pair in it: mkdir ssh && ssh-keygen -t rsa -b 4096 -N '' -f ssh/id_rsa
  • Add the public key in ssh/id_rsa.pub to the Git repository you want to access (on GitHub, as a deploy key of the repository)
  • Add the host key of your Git server to the known hosts: ssh-keyscan github.com > ssh/known_hosts. The registry refuses to connect to a server that is not listed there.
  • The registry runs as user 1000 in the container. On Linux, give it the files and keep the private key to itself: sudo chown -R 1000:1000 ssh && chmod 700 ssh && chmod 600 ssh/id_rsa
  • Mount the directory at /home/ubuntu/.ssh and point the config server to your repository, for example using Docker Compose: 
services:
  jhipster-registry:
    image: jhipster/jhipster-registry
    volumes:
      - ./ssh/:/home/ubuntu/.ssh/:ro
    environment:
      - SPRING_PROFILES_ACTIVE=prod
      - SPRING_CLOUD_CONFIG_SERVER_COMPOSITE_0_TYPE=git
      - SPRING_CLOUD_CONFIG_SERVER_COMPOSITE_0_URI=ssh://git@github.com/your-organization/your-configuration.git
    ports:
      - 8761:8761

Once the registry has started, this page shows the public key it uses, and the Cloud config page shows your configuration.
